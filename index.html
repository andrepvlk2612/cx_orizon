💾 Salvar painel

Siga os passos abaixo para salvar uma cópia com todos os seus dados e imagens.

1
Clique em "Abrir para salvar" abaixo — uma nova aba será aberta com o painel completo.
2
Na nova aba, pressione Ctrl + S para salvar o arquivo no seu computador.
3
Use o nome sugerido abaixo (ou o que preferir) e salve em uma pasta de fácil acesso.
✅ Nenhuma pasta adicional é gerada — todas as imagens ficam embutidas dentro do próprio arquivo .html, então basta compartilhar esse único arquivo.

📁 Salve em uma pasta compartilhada (ex: OneDrive, Teams) para que toda a equipe acesse sempre a versão mais recente. Arquivos de versões anteriores podem ser descartados.
